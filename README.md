# Prativa Motors Dealership Website

A simple car dealership website created using HTML and CSS.  
This project displays cars for sale, team members, and a registration form for customers.

---

## Features

- Responsive car dealership homepage
- Navigation menu
- Car showcase section
- Team member section
- Customer registration form
- Background image with overlay design
- Card-based layout using Flexbox

---

## Technologies Used

- HTML5
- CSS3

---

## Sections Included

### Home
Displays a welcome message for visitors.

### Cars
Shows available cars with:
- Car image
- Car name
- Price

### Team
Displays business team members.

### Register
Simple registration form with:
- Name
- Email
- Phone number
